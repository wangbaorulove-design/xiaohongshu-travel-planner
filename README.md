# 小红书收藏夹 → 旅行攻略

**读取你的小红书旅行收藏夹，提取景点、美食和体验，结合日期、住宿与偏好，生成有来源、可执行、能持续修改的攻略。**

核心流程：授权浏览器读取收藏夹 → 去重与逐篇提取 → 官方核验 → 按地理和时间排程 → 输出攻略与预约清单。

## 能帮你做什么

- 从收藏夹发现真正想去的地方，区分正文、图片和视频的读取范围。
- 按必去项、已订时段、交通、用餐、睡眠和酒店体验排程。
- 区分免费园区与收费子项目，提供必要购票链接。
- 新增项目后同步整份攻略，不悄悄删掉原项目。
- 保留读取进度，遇到受限页面明确报告，不假装已读完。

## 安装与第一次使用

下载本目录，命名为xiaohongshu-travel-planner，放入宿主配置的skills目录。保留SKILL.md、references、assets、agents；不需要复制真实旅行资料。安装位置由宿主配置决定。

宿主需支持Skill、文件读写、官方网页检索，以及可操作用户授权会话的浏览器或连接器。**Skill已包含读取流程；浏览器连接需要在使用环境中启用。** 不需要向仓库或聊天提供Cookie、密码和验证码。

详见[配置与第一次读取](references/setup.md)。先让助手读取收藏夹列表和一篇正文做预检，再发完整请求：

> 用 $xiaohongshu-travel-planner 读取我提供的小红书收藏夹。旅行日期、实际抵达与返程时间、住宿区域、必去项目、已订票务和节奏如下……请先报告读取覆盖，再生成每日路线、交通缓冲、强度说明、免费/收费项目与预约清单。缺少关键资料时集中问我。

## 输出

当前旅行攻略.md、收藏提取与来源.md、本地reading-progress.json。进度文件是Agent维护的记录，仓库不提供独立一键爬虫。完整演示见[虚构使用案例](examples/walkthrough.md)。

## 实测与限制

已在Codex桌面登录浏览器中完成“收藏夹列表→一篇正文→返回”实测。全夹、媒体、全新账号和其他工具路径尚未在本版本完整验证。[验证记录](references/validation-status.md)

无法访问的笔记、未解析媒体和未核实营业信息会明确标注。登录由用户完成；不绕过访问限制，不自动预订付款。项目与小红书无官方关联。

## 反馈与许可

公开包不含本机私有配置、真实收藏/行程、截图、订单或访问凭证。当前未附开源许可证，公开展示不等于授予开源许可。缺陷反馈请用脱敏复现步骤、宿主/工具版本、预期与实际结果，不上传账号信息或完整浏览器日志。
