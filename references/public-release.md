# 公开部署与能力边界

这是给支持Skill的AI助手使用的工作流程，不是独立爬虫、旅游预订系统或小红书官方产品。

需要宿主提供：文件读写、可访问公开官网的检索工具，以及读取小红书时可用的用户授权浏览器/连接器。Skill不内置这些工具，不携带账号、Cookie或API密钥。浏览器不可用时，明确受限，并可使用用户提供的导出文本或截图；只有实际读取到的内容才计入覆盖。

公开包仅包含通用规则、模板和虚构场景；排除local-profile.md、真实收藏链接、行程文件、护照/航班/订单信息、截图、日志与临时访问参数。不绕过登录、付费或访问限制；来源只做必要摘要，不重新发布完整笔记及图片。

发布前说明兼容性：当前完成文件结构检查及收藏夹列表到单篇正文的浏览器冒烟验证，详见validation-status.md，不能声称所有AI客户端兼容或任意收藏夹都能读取。公开GitHub之前确认目标账号/仓库、可见性、许可证和实际待提交文件；不把用户希望发布理解为可以公开其旅行资料。
