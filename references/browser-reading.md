# 收藏夹读取与故障定位

按当前工具文档操作，不复制旧浏览器ID、变量、DOM选择器或登录数据。小红书登录态可能只在用户当前浏览器里生效，公开网页抓取失败不能据此判断收藏夹无法读取。

## 正常读取

1. 优先定位用户已打开、已登录的准确收藏夹标签页，复用已有会话。只在当前工具支持时获取浏览器及标签列表；按当前返回ID选择，不硬编码历史ID。
2. 如果工具是cua_repl，首次调用与恢复上下文按该工具初始化/文档要求执行。后续使用文档中实际提供的浏览器接口。
3. 查看收藏夹标题、数量和可见笔记，滚动加载；去重保存标题和实际可见链接。详情页可能展示大量推荐流，提取时定位当前笔记作者、正文和媒体区域。
4. 优先打开可见的完整笔记链接。若含页面生成的访问参数，浏览期间按工具规则复用；不要猜造参数或用失效的裸ID反复试错。技能包、日志和通用示例不保存Cookie、登录凭证或个人访问参数。交付链接如必须依赖临时参数，注明可能失效，可用收藏夹链接＋标题帮助回找。
5. 图文细节不在文本树时查看实际图片，不把“已打开页面”写成“已读全部图片”。每批读取记录成功、受限和未读项目，便于续做。

## 故障判断

| 观察 | 处理 |
|---|---|
| 登录弹窗、未登录 | 请用户在同一浏览器完成登录；之后重新检查页面，不假定另一浏览器的登录已同步 |
| 已登录但公共抓取失败 | 切换到当前已登录浏览器的可见页面读取，不重复要求登录或上传截图 |
| 全局浏览器清单超时，但工具已有有效浏览器/标签句柄 | 在当前文档允许时直接复用句柄，单独读取目标标签；不要反复调用失败的全局清单 |
| 标签包装接口读取超时，但当前文档提供底层tabs接口 | 可用已选择浏览器的tabs.get等受支持接口读取，再获取DOM快照；不采用未文档化接口 |
| 页面显示“未连接到服务器”/空白 | 区分网站页面错误与浏览器工具超时；做一次有依据的重载或重新选择已知标签，再检查具体状态 |
| 没有标准heading节点 | 根据当前快照里的作者与正文定位，不能用找不到heading后的最后一个字符当正文 |
| 数量对不上 | 检查懒加载、重复、无标题条目及无法访问笔记；仍有差额则记录，不能补造条目 |

每次失败先看错误/可见页面，做一种有依据的修复；相同状态连续失败两次后换受支持的方式或明确报告具体阻塞，不无限重试。截图上传只在连接器和已登录浏览器确实不能取得必要内容时作为后备；不要在尚可操作浏览器时让用户逐篇搬运。

可能出现“全局发现失败、直接已选标签读取可用”，这是诊断线索，不是每次都应采取的固定步骤。运行时和接口会变化，以实时文档为准。
